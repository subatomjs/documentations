Core Architecture

Engineered for High-Throughput Boundaries

Designed to run anywhere data crosses trust boundaries without performance penalties or external vulnerabilities.

Dual Sync/Async Engine

Blazing fast synchronous validation for CPU-bound pipelines, with automated branching into async routines when Promises or database checks are used.

Prototype Pollution Defense

Automatic defense against __proto__ and constructor injections across object shapes, records, and merged schemas.

First-Class File Uploads

Dedicated infer.file() and infer.files() schemas with MIME checks, file extension limits, size thresholds, and storage policies.

Smart Coercion Suite

Safely convert strings from URL queries and multipart forms into typed booleans, numbers, bigints, and dates via infer.coerce.*.

O(1) Discriminated Unions

Indexed tag lookup delivers constant-time branch resolution for event payloads and state machines without test-and-fail iterations.

Zero Dependencies

Zero external runtime dependencies. Lightweight dual ESM and CommonJS bundle with 100% test branch coverage.

Idiomatic JavaScript & TypeScript Syntax

Switch between TypeScript and plain JavaScript examples anywhere in the documentation.

schemas/user.ts
import { infer, type Infer } from "subatom-infer";

// 1. Define schema with chaining & constraints
export const RegisterSchema = infer.object({
  id: infer.string().uuid(),
  handle: infer.string().min(3).max(24).toLowerCase().trim(),
  email: infer.string().email(),
  age: infer.coerce.number().int().min(18).optional(),
  plan: infer.enum(["free", "pro", "enterprise"]).default("free"),
  avatar: infer.file().mime(["image/png", "image/jpeg"]).max(5_000_000).optional(),
  joinedAt: infer.coerce.date().default(() => new Date())
}).strict();

// 2. Automatically derive static TypeScript types
export type RegisterInput = Infer<typeof RegisterSchema>;

// 3. Validate runtime payloads safely
const result = RegisterSchema.safeParse(req.body);
if (result.success) {
  console.log("Verified User:", result.data.handle);
}
